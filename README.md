# ⌨️ TypeTrace

### Every typist leaves a signature.

**TypeTrace** is a typing challenge where you don't compete with everyone else.

**You compete with yourself.**

🌐 **Live:**

https://typetrace-frontend.onrender.com
---

## 👻 Meet Your Ghost

Your previous typing performance becomes your **Ghost**.

It moves with your past typing speed while you type again.

```text
        YOU  ────────────────► 🏁
       GHOST ──────────────► 👻
```

**Can you catch it?
Can you beat it?**

---

## ⚡ What You Can Do

* ⌨️ Take typing challenges
* 👻 Race your animated Ghost
* 📈 Track WPM & accuracy
* 🔥 Maintain typing streaks
* 🏆 Unlock achievements
* 📜 View your typing history
* 👤 Manage your profile
* 🔐 Create an account & login
* 📊 Track your personal progress

## 🚀 Run It

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

For production:

```env
VITE_API_URL=https://typetrace-backend.onrender.com/api
```
